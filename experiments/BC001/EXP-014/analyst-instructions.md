# Patent review packet

Review the publications in `analyst-packet.csv` using the existing agreed
invention scope and analyst relevance standard. Do not change that standard.

For each item, complete the blank fields:

- H / M+ / M / L / N label;
- Include Yes / No;
- short reason;
- relationship to another packet item if you recognize a shared report family,
  identifying the other item by packet ID.

Use the provided access link to consult the publication. The `link_status` field
records the access check on 2026-09-16. Where unavailable, Search publication
number in Orbit. Availability may change after this check. If evidence cannot be accessed or is insufficient for a
decision, leave the label and inclusion fields blank and record the limitation
in the reason field. Do not convert inaccessible evidence into a negative label.
