| Query | Feature path |
| --- | --- |
| Q1 | F1 + F2, firearm plus authentication |
| Q2 | F1 + F3, firearm plus operational control |
| Q3 | F1 + F4→F3, location-conditioned firearm control |

The baseline and EXP015-015B each planned one monolithic Q1. Their full statements were not supplied. No unexecuted syntax is reconstructed in this record.

The original planning ranges were materially inaccurate. Their numerical values were not supplied and are not invented here. No numerical pass/fail threshold is retroactively represented as predeclared. The supplied operational outcome is excessive volume blocking export of both executed queries.
