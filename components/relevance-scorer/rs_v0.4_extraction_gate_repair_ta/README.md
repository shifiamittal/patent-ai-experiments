# rs_v0.4_extraction_gate_repair_ta

EXP-018A corrects title/abstract interpretation while preserving rs_v0.3 scoring policy. The score, sanitize, sort_key, rank_records and validate functions retain identical ASTs. Specification and schema are copied unchanged; their EXP-016A labels identify the inherited policy.

engine.py contains reusable outcome, controlled-action, word-sense, causal/adjacent-sentence and functional-architecture helpers. bc001_config.py supplies firearm vocabulary and access-versus-operation boundaries. scorer.py maps interpretation to BC001 features and inherited scoring. CORRECTIONS supports pre-freeze sequential attribution; production enables all four.

Failed and successful credential outcomes support authentication. Explicit relationships require operational control and a causal expression. Adjacent result anaphora can provide an exact multi-sentence span. Shared authentication-device reference supports inferred evidence with rationale. Registered access to firearm-coupled authentication devices plus a stated firearm lock supports inferred F3, never missing F2. Both supporting facts are recorded. Independent co-occurrence remains absent.

Functional authentication/lock/enrollment/control components prevent false generic-mechanism penalties. Bare server/station presence cannot. Existing mechanism matches remain accepted. Physical containers are separated from adjectival safe, extinguishing and access to a covered trigger.

Run python -B -m unittest discover -s tests -v here. Run experiments/BC001/EXP-018A/prepare_run.py from the repository root using UTF-8 mode on Windows. The ranking runner stages eight allowlisted files in a fresh temporary directory and denies further out-of-directory reads, network and subprocess creation. Attribution uses the same corpus and scorer without labels.

Limitations: bounded deterministic interpretation; ambiguous translated clauses, anaphora, limited adjective vocabulary and multi-purpose containers. Existing F5/F6 scope and targeting defects are outside this repair. No publication-number rules, GOLD phrases or label-conditioned scoring.

Mechanism-general; validated on BC001 only.
